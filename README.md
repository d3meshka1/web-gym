# Bonanza Gym — улучшенная версия проекта

Сохранён прежний сайт: шесть страниц, тёмная шапка, оранжевые акценты, фотографии, основная структура и Bootstrap 5.3.3. Исправления сосредоточены на работе интерфейса и связанных сценариях посетителя.

## Запуск

1. Распакуйте **весь архив**.
2. Откройте `web-gym-main/index.html` в браузере. Сборка, Node.js и база данных не нужны.
3. Для разработки удобнее открыть папку в VS Code и запустить `index.html` через **Live Server**. Альтернатива, если Python уже установлен: `python3 -m http.server 8000`, затем `http://localhost:8000`.

jQuery 3.7.1 Full сначала подключается с CDN, как требует задание. Если CDN недоступен, включается локальная резервная копия. Bootstrap и изображения находятся в архиве. При первом запуске без Интернета браузер может ждать завершения запроса к CDN; затем работают локальные скрипты. Сохранение отзывов и корзин зависит от разрешений браузера, особенно при открытии через `file://`; при запрете хранения сайт продолжает работать в текущем окне и показывает сообщение.

## Что работает

- **Главная:** выбор тарифа с ценой и переходом в запись; поиск и фильтр отзывов; добавление, оценка, счётчик символов, дата и удаление собственных отзывов.
- **Клуб и расписание:** совместные фильтры по названию, дню, направлению, тренеру и свободным местам; ближайшая дата занятия; перенос выбора в запись.
- **Услуги:** поиск, категории, сортировка, расчёт стоимости нескольких пакетов, выбор тарифа и корзина услуг.
- **Запись:** самостоятельный визит, персональная тренировка или группа; проверка контактов, возраста, даты, времени, вместимости и совместимости тарифа; живой итог; полная демонстрационная квитанция.
- **Питание:** каталог, категории, поиск, сортировка, фасовки, цены, корзина; отдельные сценарии заказа и консультации.
- **О нас:** FAQ с поиском, категориями, раскрытием ответов и клавиатурой; форма обращения с проверкой и итогом.
- **Общее:** корректные ссылки, активная навигация, переход к содержимому, кнопка «Наверх», понятные пустые состояния и безопасное сохранение корзин.

Все формы — **учебная демонстрация**: данные не отправляются на сервер, места не резервируются, письма не отправляются, реальные заказы и платежи не создаются. Контактные поля заявок не записываются в localStorage. В браузере сохраняются только выбранные позиции/количества и отзывы, которые посетитель сам добавил.

## Сохранение HTML/CSS — исправления основы

Основа — предоставленный `web-gym-main.zip`. Истории Git и тега `midterm` в архиве нет; новая история и фиктивные теги не создавались. Используйте файлы в существующем репозитории вашего проекта.

Три авторских CSS (`base.css`, `demezhan.css`, `yerassyl.css`) **побайтово совпадают с исходниками**. Новые пользовательские CSS-правила не добавлялись. Интерфейсные элементы, состояния и изменения текста создаются JavaScript/jQuery через DOM и существующие классы. Эффекты выполняет jQuery.

Перед доработкой были зафиксированы необходимые исправления подключений:

| Исходная ошибка | Исправление |
| --- | --- |
| Три страницы ссылались на отсутствующий `css/yerrasyl.css` | Указан существующий `css/yerassyl.css`. |
| Две страницы подключали отсутствующий `css/interactive.css` | Удалено лишнее подключение: его правила уже находятся в исходном `demezhan.css`. |
| Пункт «О нас» ссылался на отсутствующий `about.html` | Ссылка ведёт на `colophon.html`. |
| booking.js использовал `$`, но jQuery не подключался | jQuery подключён перед скриптами проекта; предусмотрен локальный резерв. |
| Bootstrap зависел от сети, порядок подключения отличался | Та же версия 5.3.3 включена локально; все скрипты загружаются с `defer`. |

Это технические исправления исходной основы, а не заявка на баллы за новый HTML/CSS. За пределами перечисленных исправлений и script-подключений исходная HTML-разметка сохранена.

## Единые правила данных

- Восемь исходных цен тарифов сохранены: **11 000 / 13 000 / 10 000 / 40 000 / 80 000 / 46 000 / 2 000 / 3 000 ₸**. Общий источник — `js/main.js`.
- Часы клуба: ежедневно **07:00–23:00**. Дневные тарифы: **08:00–15:00**. Вечерние: **15:00–23:00**, в воскресенье до **21:00**. Часовой визит должен целиком помещаться в интервал.
- Возраст в форме: **16–90**, только целое число. Дата: сегодня или в пределах **90 дней**; прошедшее время сегодня отклоняется. Начало с шагом 30 минут.
- Самостоятельный визит: **1–6** человек; каждому нужен отдельный пакет. Персональный: **1** человек, пакет **12 занятий**, выбирается дата первого. Группа: не больше показанных свободных мест.
- Противоречие исходного тарифа «школьники до 16 лет» и `min=16` разрешено названием **«Студенческий»** с подтверждением наличия билета. Это согласующее учебное допущение, которое можно отдельно обсудить с преподавателем.
- Групповые занятия: **2 500 ₸/участник, 60 минут**. Расписание и места — демонстрационные. Четверговое кардио начинается в **19:00**, чтобы час занятия завершался в 20:00 по графику тренера.
- Базовые цены шести товаров сохранены. Цены дополнительных фасовок — явно указанные демонстрационные данные.
- Неподтверждённые скидки, обещания отправки и автоматического звонка удалены из активного интерфейса.
