# Bonanza Gym

Учебный сайт на HTML, CSS, Bootstrap 5.3.3 и jQuery 3.7.1 Full. Сохранены тёмная шапка, оранжевые акценты и основная структура проекта.

## Запуск

1. Распакуйте весь ZIP.
2. Откройте `index.html` в папке `web-gym-main-2`.
3. Для разработки и общего хранилища между страницами удобно использовать Live Server в VS Code. Если установлен Python, из папки проекта можно выполнить `python3 -m http.server 8000` и открыть `http://localhost:8000`.

Сборка и установка пакетов не нужны. jQuery сначала загружается с CDN; при недоступности сети используется локальная копия. Bootstrap, фотографии и остальные ресурсы включены в архив.

## Страницы

| Файл | Возможности |
| --- | --- |
| `index.html` | Информация о клубе, компактное фото, зоны клуба, выбор тарифа, контакты и переход к отзывам. |
| `branche.html` | Информация о клубе, карта, расписание с поиском и фильтрами. Для записи есть ссылка на отдельную страницу. |
| `services.html` | Тарифы, поиск, сортировка, расчёт стоимости и корзина услуг. |
| `booking.html` | Единственная форма записи: самостоятельный визит, персональная тренировка или группа. Здесь же собрана информация о ведущих тренерах. |
| `nutrition.html` | Каталог питания, фасовки, корзина, форма заказа или консультации. |
| `reviews.html` | Отзывы, поиск, фильтр оценок, добавление и удаление своих отзывов. |
| `colophon.html` | Информация о клубе, FAQ и форма обращения. |

## Изменения в этой версии

- Зоны на главной оформлены как информационный список, без внешнего вида кнопок.
- Большие фотографии зала на главной и странице услуг уменьшены. Карта сохранена в прежнем размере.
- Повторяющиеся карточки тренеров удалены из услуг. Ссылка ведёт в `booking.html#trainers-section`.
- В расписании удалены выбор занятия и панель выбранного занятия. Выбор и оформление визита происходят только в `booking.html`.
- Глоссарий удалён.
- В полях телефона записи и питания сразу стоит `+7`. Поддерживается вставка номера с `+7`, с `8` или десяти цифр без кода страны. После сброса формы префикс сохраняется.
- Блок «Ваш выбор» удалён из записи. Проверки полей и подтверждение успешно заполненной заявки с итоговой суммой сохранены.
- Отзывы перенесены в `reviews.html`, их логика — в `js/reviews.js`. На всех страницах добавлен пункт меню «Отзывы».

## Данные и сохранение

Тарифы, тренеры, расписание и общие проверки находятся в `js/main.js`. У каждой страницы есть отдельный скрипт. Общая обработка номера телефона находится в `js/phone.js`.

Формы работают как учебная демонстрация: данные не отправляются на сервер, реальные записи, заказы и платежи не создаются. Контактные данные заявок не сохраняются. Корзины и собственные отзывы хранятся в браузере. Ключ отзывов `bonanza.reviews.v1` сохранён; при работе с прежним адресом сайта ранее сохранённые записи доступны на странице отзывов. При открытии через `file://` доступность и область хранилища зависят от браузера.

Новые отзывы видны только в браузере, где они созданы. Если браузер запрещает сохранение, страница сообщает об этом и работает до обновления.

`js/old-js/` содержит прежние версии скриптов для сравнения; они не подключены к страницам. Исходные фотографии, зависимости и материалы проекта сохранены.

## Выполненная проверка

- Синтаксис всех девяти активных JS-файлов.
- Все семь HTML-страниц: локальные ресурсы, ссылки и якоря, уникальность ID, активные пункты меню, порядок подключения скриптов.
- Наличие единственной формы записи и удаление глоссария, повторных карточек тренеров и блока «Ваш выбор».
- Обработчики номера: корректные и некорректные вставки, сохранение `+7`, редактирование, отправка и сброс формы.

Полный визуальный и интерактивный прогон в браузере не выполнялся: среда проверки запрещает запуск локального браузера и открытие локальных файлов в облачном браузере.
