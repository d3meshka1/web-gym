Исходные JS-файлы из переданного архива. Сохранены без исправлений для сравнения с текущей jQuery-версией.
НЕ подключать к страницам одновременно с текущими скриптами. Здесь могут оставаться исходные ошибки, включая обращение к card в booking.js.
Исходный booking.js уже использовал jQuery. В качестве трёх переводов с native JS используются services.js, home.js, about.js; см. docs/JQUERY.md.
