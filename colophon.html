Technical Implementation & Status

This website is currently under development by student group SE-2533 for the underground gym Iron Dungeon Gym in Astana. The project is implemented exclusively in pure semantic HTML5 without using Cascading Style Sheets (CSS), JavaScript, frameworks, or site builders, in strict compliance with the assignment requirements. Our primary academic goal is to master document structure, element hierarchy, and accessibility before introducing any presentation layers.

Team Responsibilities & Current Progress

Our team consists of two members actively working on the site architecture. We divided the workload to ensure parallel progress using version control.

  • Student 1: Responsible for the main landing page layout, branch locations, and the membership pricing architecture (pages in progress).
  • Student 2: Responsible for the complex data presentation pages, specifically the interactive group schedule page (schedule.html) and the comprehensive gym facilities breakdown (facilities.html — fully implemented).
