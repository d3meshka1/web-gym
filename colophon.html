Технологический стек и окружение

Этот проект разработан в рамках курса по веб-технологиям студентами группы SE-2533 Astana IT University. Проект выполнен исключительно на чистом семантическом HTML5 без использования фреймворков и таблиц стилей (CSS).

Обязанности команды и распределение страниц

Наша команда состоит из двух участников. Мы разделили обязанности по созданию файлов и секций сайта, чтобы эффективно использовать контроль версий и параллельно вести разработку.

  • Kaidar Demezhan (Студент 1): Отвечает за разработку главной страницы (index.html) с отзывами и контактами, страницу про зал и расписания (branches.html) а также отвечает за разработку страницы услуг и прайс-листа (services.html),
  • Yerrasyl Sagimgaliyev(Студент 2): Отвечает за техническую страницу colophon (colophon.html). интерактивной формы онлайн-бронирования (booking.html), а также страницы рекомендаций по спортивному питанию (nutrition.html).

Инструменты разработчика

В процессе работы над проектом использовались следующие команды и утилиты командной строки: 

git init
git add .
git commit -m "Initial commit for Bonanza Gym static website structure"
git branch -M main
git remote add origin https://github.com/bonanzagym/web-assignment.git
git push -u origin main

Для проверки ввода данных в консоли использовалась команда Ctrl + C или Cmd + Option + I для вызова панели разработчика в браузере.

Пример вывода успешной сборки в терминале:

Building HTML structure... OK. W3C validation passed with 0 errors.
